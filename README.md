# Windows Security & Administration Cheat Sheet


A collection of Windows commands for system administration, security auditing, and incident response.

## Usage

Each file contains commands with their explanations. Commands are provided as-is for reference and educational purposes. Use with caution, especially destructive commands.

## Disclaimer

Some commands may modify system state, delete data, or alter security settings. Always test in a safe environment before applying to production systems.
I had to learn the hard way. Please be careful.
